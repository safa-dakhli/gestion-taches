# Application python de gestion des taches
Application console simple pour gérer des taches quotidiennes.

## Fonctionnalités
- Ajouter une tache (le titre vide est refusé)
- Afficher toutes les taches avec leur numéro
- Rechercher une tache par mot_cle
- Quitter le programme

## Etapes réalisées
1. Creation du programme main.py
2. Test avec Run Python File
3. Initialisation de Git et commits
4. Publication sur GitHub avec git push

## Exécution
ouvrir main.py dans vs code, puis cliquer sur le bouton Run Python File.
